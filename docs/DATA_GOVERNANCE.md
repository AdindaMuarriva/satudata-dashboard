# Tata Kelola Data dan AI

Setiap chart dan jawaban asisten harus menunjukkan dataset sumber, OPD, periode, satuan, serta waktu pembaruan bila tersedia. Nilai dihitung di browser dari baris data portal; model AI hanya menulis narasi dari ringkasan statistik dan tidak boleh menambah fakta atau angka.

Sebelum publikasi, pengelola wajib memeriksa definisi indikator, satuan, cakupan wilayah/periode, dan catatan keterbatasan pada metadata dataset portal. Umpan balik asisten disimpan lokal pada perangkat pengguna dengan key `satudata_ai_feedback`; jangan perlakukan sebagai data survei resmi tanpa persetujuan dan mekanisme penyimpanan yang sesuai.
